# Governance Process

Every artifact follows the same lifecycle.

1. Product Manager creates or revises the artifact.
2. Reviewer evaluates the artifact.
3. Product Manager revises if required.
4. Reviewer confirms recommendations have been addressed.
5. QA validates the artifact.
6. Approved artifacts become the project baseline.
