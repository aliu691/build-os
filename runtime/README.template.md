# BuildOS Runtime Configuration

This directory contains the runtime configuration and instructions for BuildOS-generated projects.

## Contents

- **buildos.json** — Project identity and configuration
- **instructions.md** — Runtime instructions for AI agents
- **prompts/** — Placeholder for project-specific prompts
- **roles/** — Placeholder for project-specific role overrides
- **templates/** — Placeholder for project-specific templates

## Getting Started

1. Review `buildos.json` to understand your project configuration
2. Read `instructions.md` to understand runtime expectations
3. Populate prompts/, roles/, and templates/ with project-specific assets

## For BuildOS Maintainers

This directory structure is a template. When generating a new project, clone this structure and populate it with project-specific configuration.

Do not modify this template directly unless changing the BuildOS runtime specification.
